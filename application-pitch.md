# Application Pitch

### OnDeck

Friend groups are constantly sending each other restaurants, events, hikes, and other things they want to do, but when it is finally time to make plans, those ideas are often buried in old messages or missing the context needed to decide whether they still work. OnDeck gives each friend group a lightweight shared collection of things they want to do, so ideas discovered now are easy to use later.

### Key Features

**Quick Add**

When someone finds something the group might want to do, they can quickly add it to OnDeck by pasting a link or entering it manually. For supported links, OnDeck can extract basic information such as the activity name, location, date, or description so saving an idea does not turn into filling out a form.

This helps activity suggesters preserve recommendations with very little extra effort, while giving the rest of the friend group a shared place to recover those ideas later instead of searching through old chats.

**Group Interest**

Each saved activity keeps track of the group’s relationship to it. Members can indicate that they want to do it, have already done it, or would do it again.

This helps friend group members preserve the social context around an idea, rather than remembering only that “someone sent this restaurant a few weeks ago.” It also makes it easier to see whether an activity still makes sense for the particular people who are considering it.

Different friend groups can maintain separate collections, so the same person can keep different ideas and preferences with roommates, college friends, family, or other groups.

**Pick for Now**

When it is time to make plans, users can select the friends who are participating and see promising activities the group has already saved. OnDeck can prioritize ideas those people want to do and have not already done, while allowing the group to narrow the options using useful constraints such as activity type, location, cost, or available time.

This helps people making a particular plan avoid starting from scratch and quickly recover options that are relevant to the specific subset of friends who are available.

OnDeck does not try to choose the perfect plan or turn hanging out into a formal voting process. Instead, it resurfaces a small set of ideas the group was already excited about, reducing repetitive searching while still leaving the final decision and the spontaneity of making plans to the group.
